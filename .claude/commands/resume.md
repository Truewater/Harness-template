이전 세션의 작업을 인수인계 문서로부터 이어받는다.

## 절차

1. `.omc/handoffs/`에서 가장 최근 문서를 읽는다 (`ls -t .omc/handoffs/ | head -1`). 인자로 파일이 지정되면 그 파일을 읽는다: $ARGUMENTS
2. `git status --short --branch`, `git diff --stat`으로 문서의 "현재 상태"와 실제 상태가 일치하는지 확인한다.
3. CLAUDE.md "명령어" 섹션의 테스트 명령을 실행해 문서에 기록된 결과와 같은지 확인한다.
4. 문서의 "읽어야 할 파일"과 "다음에 할 일" 첫 항목에 필요한 파일만 읽는다.
5. 아래 형식으로 짧게 보고한 뒤 "다음에 할 일" 첫 항목부터 진행한다. 2~3단계에서 불일치가 있으면 진행하지 말고 불일치 내용을 먼저 보고한다.

```
이어받은 작업: {목표}
상태 확인: 브랜치 ✅/❌ · 변경 파일 ✅/❌ · 테스트 ✅/❌
다음 작업: {첫 항목}
```

## 금지사항

- 코드베이스 전체를 탐색하지 마라. 이유: 새 세션이 시작부터 컨텍스트를 크게 쓰면 세션당 컨텍스트 예산(30%)을 곧바로 다시 넘긴다.
- 문서의 "결정 사항"을 근거 없이 뒤집지 마라. 이유: 이전 세션이 대안을 검토하고 버린 결과다. 뒤집어야 한다면 이유를 사용자에게 먼저 제시한다.
