## 디자인 원칙
<!-- 1번은 프로젝트 고유 원칙으로 채운다. 2~6번은 공통 기본 규칙 — 프로젝트에 맞게 수치만 조정한다. -->
1. {예: 도구처럼 보여야 한다. 장식보다 정보}
2. 화면당 Primary 동작은 하나. 파괴적 동작(삭제 등)은 별도 스타일로 구분하고 주요 동작과 떨어뜨려 배치한다.
3. 긴 폼·플로우는 단계로 나누고 진행 상태(현재/남은 단계)를 표시한다.
4. 간격은 {4|8}px 배수 스케일만 사용한다. 그룹 내부 간격 < 그룹 사이 간격.
5. 접근성: 텍스트 대비 WCAG AA(본문 4.5:1, 큰 텍스트 3:1), 색만으로 정보 전달 금지, 모든 인터랙션 키보드 접근 + 포커스 표시, 아이콘 전용 버튼에 `aria-label`, 이미지에 `alt`.
6. 데이터를 표시하는 컴포넌트는 로딩 / 빈 상태 / 에러 상태를 모두 가진다.

## AI 슬롭 안티패턴 — 하지 마라
<!-- 검사 패턴은 /review가 `grep -nE`로 기계적으로 확인한다(쉼표로 나뉜 패턴은 각각 실행). 스택(Tailwind/CSS-in-JS 등)에 맞게 조정. -->
| 금지 사항 | 이유 | 검사 패턴 |
|-----------|------|------|
| backdrop-filter: blur() | glass morphism은 AI 템플릿의 가장 흔한 징후 | `backdrop-filter`, `backdrop-blur` |
| gradient-text (배경 그라데이션 텍스트) | AI가 만든 SaaS 랜딩의 1번 특징 | `bg-clip-text`, `background-clip:\s*text` |
| "Powered by AI" 배지 | 기능이 아니라 장식. 사용자에게 가치 없음 | `Powered by AI` |
| box-shadow 글로우 애니메이션 | 네온 글로우 = AI 슬롭 | `glow`, `animate-pulse` (수동 확인) |
| 보라/인디고 브랜드 색상 | "AI = 보라색" 클리셰 | `purple-[0-9]`, `violet-[0-9]`, `indigo-[0-9]` |
| 모든 카드에 동일한 rounded-2xl | 균일한 둥근 모서리는 템플릿 느낌 | `rounded-2xl`, `rounded-3xl` (빈도 확인) |
| 배경 gradient orb (blur-3xl 원형) | 모든 AI 랜딩 페이지에 있는 장식 | `blur-3xl` |
| 이모지 아이콘 | 도구형 UI의 톤과 맞지 않음 | 수동 확인 |
